# RP235x Sync Examples
These examples were developed and validated with a [Pico 2 W](https://www.raspberrypi.com/products/raspberry-pi-pico-2/) with the [Adafruit MPRLS](https://www.adafruit.com/product/3965) breakout board. For
different hardware combinations, it's important to verify the pin mappings, serial interface and the I2C address
(if relevant).

## Usage
E.g. `$ cargo run --bin i2c_read`
